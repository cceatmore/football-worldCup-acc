# 足球彩票盈亏记账

一款面向个人用户的 **足球彩票记账 Web 应用**。帮助你在看比赛、买方案之后，把「花了多少、回来多少、最终盈亏多少」记录清楚，而不是依赖零散聊天记录或表格。

纯静态页面，**无需后端、无需数据库**，部署到 GitHub Pages 后，电脑和手机浏览器均可使用。

---

## 这个项目是做什么的？

看球买彩时，常见问题是：

- 同一场比赛下了多个玩法，事后记不清具体选项
- 串关方案跨多场比赛，消费和回报分散，难以汇总
- 赛后才知道盈亏，但缺少按时间、按比赛回看的数据

本项目把 **比赛 → 方案 → 消费 / 返回 → 盈亏** 串成一条清晰的记录链路，适合：

- 个人或小范围朋友 **自用记账**
- 2026 世界杯等大赛期间，按场次跟踪投注与结果
- 需要 **移动端随时查看**、又不想安装 App 的场景

> 本工具仅用于个人记账与数据统计，**不提供购彩、荐彩、支付或任何官方接口**，与体彩/福彩等官方平台无关联。

## 主要功能

### 比赛

- 内置 2026 世界杯小组赛 **72 场**赛程（北京时间）
- **当前赛事 / 赛事历史** 分栏展示
- 一键 **刷新比赛列表**，从公网同步赛果（支持手动补录）
- 支持新增、编辑比赛与赛果

### 方案

- 竞彩式选场：胜平负、让球、比分、总进球、半全场等
- 支持 **单关至 8 串 1** 等多种投注方式组合
- 同一场比赛多个玩法合并展示，避免重复刷屏
- 方案可 **编辑**；返回金额单独填写，支持填 `0` 与「未填写」区分

### 数据

- 汇总总消费、总返回、净盈亏
- 按 **今天 / 最近 7 天 / 全部** 与 **关联比赛** 筛选
- 方案列表支持盈利 / 亏损 / 未结算筛选

### 账号与隐私

- 本地注册登录，**数据只存在你的浏览器**里
- 不同账号互不干扰，密码在浏览器端哈希存储

## 技术特点

| 项目 | 说明 |
|------|------|
| 形态 | 静态 H5（`index.html` + `styles.css` + `app.js`） |
| 依赖 | 无构建步骤，无 npm 依赖 |
| 存储 | `localStorage`（`football-ledger-v2`） |

## 快速开始

```bash
# 克隆或下载本仓库后，在项目目录执行：
python -m http.server 8080
```

浏览器打开 [http://localhost:8080](http://localhost:8080)，注册账号即可使用。

同一 WiFi 下，手机可访问 `http://<你的电脑局域网IP>:8080`。

---

## 部署到 GitHub Pages

1. 将本仓库推送到 GitHub（公开仓库）
2. 打开 **Settings → Pages**
3. Source 选 **Deploy from a branch**，Branch 选 `main`，目录选 **`/ (root)`**
4. 等待部署完成后，通过以下地址访问：

```text
https://<你的用户名>.github.io/<仓库名>/
```

手机浏览器打开上述链接即可；可「添加到主屏幕」当作快捷方式使用。

## 数据说明

- 数据 **不会上传** 到任何服务器，换设备 / 换浏览器需重新注册
- 清除浏览器网站数据会 **永久删除** 本地记录，请注意备份习惯
- 如需重置本机全部测试数据，在浏览器控制台执行：

```javascript
localStorage.removeItem("football-ledger-v2");
localStorage.removeItem("football-ledger-v1");
localStorage.removeItem("football-ledger-current-user");
location.reload();
```
